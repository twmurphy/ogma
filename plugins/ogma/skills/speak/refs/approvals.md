# Approvals

Reference for [`speak`](../SKILL.md).

Use this when you need the user to say yes before you act. That covers any response ending in a proposal to act, including a small edit you are confident about.

State the action in the user's terms -- what changes, and where. One approval per response, covering one action.

A trailing question is not an approval. "Want me to apply this?" reads as conversation, so it is easy to scroll past, and it gives the user nothing definite to answer. Close with the block below instead.

---

## Lay out in one section

```markdown

---
**Proposed:** <Action being approved>

**Approve?** (Y/N)

```
